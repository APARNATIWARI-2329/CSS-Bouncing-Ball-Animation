# ⚽ CSS Bouncing Ball Animation

A simple animation project built using HTML and CSS that simulates a bouncing ball effect through CSS Keyframes and animation properties.

---

## ✨ Features

* Smooth bouncing ball animation
* CSS Keyframes implementation
* Multiple animations running simultaneously
* Responsive container layout
* Pure HTML and CSS solution

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Animations
* Keyframes

---

## 📚 Concepts Practiced

* CSS Keyframes
* Animation Properties
* Positioning (Absolute & Relative)
* Motion Effects
* Responsive Design Basics

---

## 🎯 Learning Outcomes

This project helped me understand:

* Creating animations using CSS
* Combining multiple animations
* Working with positioning and movement
* Building interactive visual effects without JavaScript
